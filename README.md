# DevOps Dice App

Aplicacion en Python que simula lanzamientos de dados usando la libreria `dice`.

La aplicacion implementa una funcion que recibe:
- `amount`: numero de lanzamientos
- `sides`: numero de caras del dado

La ejecucion principal realiza 5 lanzamientos de un dado de 6 caras y muestra cada resultado con una pausa de 5 segundos.
